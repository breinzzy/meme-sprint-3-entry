One image meme about an AI agent that has gone rogue: my agent broke up with my girlfriend — and kept the dog. A phone chat, drawn with Pillow by `build.py`: the agent takes "we need to talk" literally, does the talking itself, and keeps the dog.

## Run it

```sh
python3 build.py   # redraws entry.png (1024x1024)
node main.ts       # copies entry.png to /output/entry.png (set MAKEFUN_OUTPUT_DIR to override)
```
